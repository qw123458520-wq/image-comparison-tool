# 应用图标转换指南

## 📍 当前状态

✅ **已创建 SVG 源文件：** `build/icon.svg`

现在需要将 SVG 转换为各平台需要的格式。

---

## 🚀 快速转换（推荐方法）

### 方法一：使用在线工具（最简单）

#### 步骤 1：SVG → PNG（1024x1024）
1. 打开：https://svgtopng.com/
2. 上传 `build/icon.svg`
3. 设置尺寸为 **1024x1024**
4. 下载生成的 `icon.png`
5. 将 `icon.png` 保存到 `build/` 目录

#### 步骤 2：PNG → ICNS（macOS）
1. 打开：https://cloudconvert.com/png-to-icns
2. 上传刚才的 `icon.png`
3. 点击"Convert"
4. 下载 `icon.icns` 并保存到 `build/`

#### 步骤 3：PNG → ICO（Windows）
1. 打开：https://cloudconvert.com/png-to-ico
2. 上传 `icon.png`
3. 在设置中选择包含多个尺寸（16, 32, 48, 64, 128, 256）
4. 下载 `icon.ico` 并保存到 `build/`

#### 步骤 4：PNG 备份（Linux）
- 将 `icon.png` 复制一份到 `build/` 目录
- Linux 直接使用 PNG 格式

---

### 方法二：使用 macOS 自带工具

如果您有一个 1024x1024 的 PNG 文件，可以用命令行转换：

```bash
# 进入项目目录
cd /Users/chenpeng/Desktop/image-comparison-tool/build

# 创建 iconset 目录
mkdir icon.iconset

# 生成多种尺寸（需要先有 icon.png）
sips -z 16 16     icon.png --out icon.iconset/icon_16x16.png
sips -z 32 32     icon.png --out icon.iconset/icon_16x16@2x.png
sips -z 32 32     icon.png --out icon.iconset/icon_32x32.png
sips -z 64 64     icon.png --out icon.iconset/icon_32x32@2x.png
sips -z 128 128   icon.png --out icon.iconset/icon_128x128.png
sips -z 256 256   icon.png --out icon.iconset/icon_128x128@2x.png
sips -z 256 256   icon.png --out icon.iconset/icon_256x256.png
sips -z 512 512   icon.png --out icon.iconset/icon_256x256@2x.png
sips -z 512 512   icon.png --out icon.iconset/icon_512x512.png
sips -z 1024 1024 icon.png --out icon.iconset/icon_512x512@2x.png

# 转换为 icns
iconutil -c icns icon.iconset

# 清理临时文件
rm -rf icon.iconset
```

### 方法三：使用专业工具（可选）

#### Figma / Sketch / Adobe Illustrator

2. 导出为 PNG（1024x1024）
3. 再使用在线工具转换为 ICNS/ICO

## 🆘 问题排查

### Q: 在线工具转换后图标模糊？
A: 确保 PNG 尺寸至少 1024x1024，不要使用低分辨率图片。

### Q: macOS 图标显示不正确？
A: ICNS 文件需要包含多种尺寸。使用 cloudconvert 或 iconutil 确保包含完整尺寸。

### Q: 暂时不想设置图标？
A: 可以跳过，使用系统默认图标。打包时会自动使用 Electron 默认图标。

---

## 💡 提示

- **推荐尺寸：** 1024x1024 或 512x512（高分辨率）
- **文件格式：** PNG 无损格式，背景透明或纯色
- **设计风格：** 简洁、可识别、在小尺寸下清晰可见
